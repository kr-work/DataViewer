# Experiment Workbench

センサから得た任意の時系列データを、読み込む・確認する・同期する・処理する・比較する・再現するための
汎用デスクトップツールです。
フィルタ（バターワース・移動平均など）、微分・積分、カルマンフィルタ系（KF / EKF / 適応 KF）などの
解析を、保存・再適用できる形でかけられるようにすることを目指しています。

製品要件は [docs/SPEC.md](docs/SPEC.md)、設計判断の記録は [docs/DECISIONS.md](docs/DECISIONS.md) を参照してください。

フィルタ・値の変換・微分・積分・カルマンフィルタ・時間の処理をボタンで選ぶと結果が表示され、スライダーや数値を

## GUI の起動と基本操作

```bash
uv run ewb                  # 起動
uv run ewb path/to/data.csv # ファイルを開いて起動
```

1. ファイルをウィンドウへドロップするか、「ファイルを開く」で選びます。すぐにグラフに表示されます。
   読み方（文字コード・区切り文字・前置きの行・時刻列・単位）は中身から判定します。時刻の列が分からないときや
   読めないときだけ、理由を添えて確認の画面が出ます。読み方を自分で決めたいときは
   「ファイル → 読み込み設定を指定して開く」を使います。
2. 左の一覧のチェックで、グラフへの表示を切り替えます。チャンネルが 7 個以上あるファイルは、最初の 6 個を表示します。
3. チャンネルをクリックして、右の処理のボタンを押すと、結果がグラフに重なります。
4. スライダーや数値を変えると、その場で結果が更新されます。保存は自動です。
5. 同じ内容のファイルを開くと、前回の続きから始まります。

データの異常（NaN・時刻の飛びなど）は隠さず、メッセージの欄に表示します。元のファイルは変更しません。
時刻の単位が列名から分からないときは秒として読み、そのことをメッセージで知らせます。

保存先は `%LOCALAPPDATA%\ExperimentWorkbench\workspaces`（Windows）などに自動で作ります。場所を自分で決めたいときは
「ファイル → 保存先を指定して始める」を使います。保存先は自動では消えません。

グラフの操作（ステータスバーと「操作方法」にも表示されます）:

| 操作 | 動き |
|---|---|
| 左ドラッグ | 選んだ時間の範囲を拡大（連動しているパネルも一緒に動く） |
| ダブルクリック、Ctrl+0、「全体を表示」 | すべてのパネルで全体を表示（縦軸も自動に戻す） |
| ホイール | 時間軸のズーム |
| 下のスクロールバー、右ドラッグ | 時間軸の移動 |
| クリック | カーソルをその位置に移動して値を読む |
| Shift + ホイール、縦軸の上でホイール | 縦軸のズーム |
| 凡例の色の四角をクリック | その系列を一時的に隠す |
| パネルの × | パネルを閉じる（データは消えません） |
| 一覧のチャンネルをパネルへドラッグ | そのパネルに重ねて表示 |

縦軸は、見えている範囲のデータに自動で合わせます。

図の読み方:

- パネルの見出しは、チャンネル名と単位です。値はクリックした位置の分だけ表示します。
- 処理の結果を重ねると、元の線は「生データ」としてグレーになります。
- 微分・積分のように単位や桁が変わる結果は重ねず、元の線のすぐ下のパネルに出します。
- フィルタが取り除いた成分は、左の一覧の「除去成分」にチェックを入れると、元の線のすぐ下に出ます。

開いている状態で別のファイルを開くと、同じ画面に追加します。このとき、同じ時計で記録したかを尋ねます。
同じ時計なら時間軸を連動して比べられます。別の時計なら時刻を揃えず、別の時間軸で表示して警告を出します
（異なる装置の時刻を勝手に揃えないため）。

## GUI での解析と調整

1. 左の一覧でチャンネルをクリックすると、処理の対象になります。
2. 右の処理のボタン（バターワース・移動平均・Savitzky-Golay・オフセット除去・微分・積分・KF・EKF・AKF など）を押すと、
   すぐに計算して結果を表示します。
3. 条件を変えると、少し待ってから自動で再計算します。主要な数値はスライダーで動かせます。不正な値や計算できない
   条件は理由を表示します（計算できない条件は保存しません）。
4. 「複製して比べる」で同じ条件の処理を増やすと、条件を変えた結果を重ねて見比べられます。
5. 一覧の処理の行をクリックすると、条件を調整し直せます。「削除」で取り除けます（元のデータは消えません）。
6. カルマンフィルタ:
   - KF（運動学モデル）: 値とその微分（速度など）を推定します。不等間隔の時刻にも対応します。
   - EKF（多項式の観測）: センサの出力 z が推定したい量 x の多項式 z = c0 + c1·x + … のとき、x とその
     変化率を推定します（センサの出力から物理量を推定するなど）。
   - AKF: 観測雑音 R を逐次推定します。
   - 線形モデル: モデルの欄で選ぶと、状態遷移 F・観測 H・プロセス雑音 Q・観測雑音 R を数値で指定できます
     （等間隔の時刻が必要）。
   - 初期値は入力データから自動で入ります（雑音の推定値など）。「データから初期値を作る」で初期状態だけを
     作り直せます。
   - 推定値は ±σ の帯付きで入力に重なります。微分・イノベーション・√R は、一覧のチェックで別のパネルに表示します。
     観測が欠測で更新しなかった時刻には × 印が付きます。
   - 長い計算は進捗バーが出て、「中止」で止められます。

## 値の変換・時間の処理・区間統計

どれも元のデータは変えず、結果を別の系列として作ります。

| 処理 | 内容 | 補足 |
|---|---|---|
| オフセット除去 | 平均値または指定値を差し引く | 無負荷の区間の平均を選ぶと、ゼロ点補正になる |
| 線形変換 | y = a x + b で変換 | 校正係数の適用や単位換算。変換後の単位を指定できる |
| トレンド除去 | 最小二乗で当てはめた多項式を差し引く | 0 次は平均値、1 次は直線。除去成分も見られる |
| 絶対値 | 値の絶対値 | |
| 正規化 | Z スコア・最小-最大正規化・ピーク正規化 | 無次元になる |
| 区間の切り出し | 選んだ区間だけを取り出す | 時刻は元の時間軸のまま |
| リサンプリング | 等間隔の時刻に変換 | 周波数を下げるときは、既定でアンチエイリアスフィルタをかける |
| 欠損の補間 | 欠損（NaN）を前後の値から補間 | 補間した点に × 印が付く。両端は外挿になるので埋めない |
| 区間統計 | 統計量とヒストグラム | 欠損は除いて計算し、その数を示す |

- 時刻が飛んでいる区間（行ごと欠けた区間）は、欠損の補間では埋まりません（値を入れる時刻がないため）。結果の文に
  飛びの数と長さが出ます。埋めるときは、リサンプリングの「欠損とみなす間隔の倍率」を大きくしてください。
- 処理の結果を別の処理の入力にすることはまだできません（生データのチャンネルにだけ処理をかけられます）。

## 入出力関係の解析

入力と出力の 2 チャンネルの関係を調べます。

1. 一覧で入力のチャンネルをクリックし、「ステップ応答」「ヒステリシス」「相互相関」のどれかのボタンを押します。
2. 「出力チャンネル」を選びます（既定は同じファイルの別の列です）。
3. 「解析範囲を指定」をオンにすると、グラフに青い帯が出ます（ステップ応答では最初からオン）。帯の両端をドラッグして、
   解析範囲を選びます。数値を入力しても、「表示範囲に合わせる」でも選べます。
4. 下の「解析結果」に、結論の一文、グラフ、指標の表が出ます。範囲を動かすと更新されます。
   グラフの上の ①〜④ は、縦並べ表示の印の番号と対応しています。表の行にマウスを置くと、指標の定義が出ます。

| 解析 | 範囲の選び方 | 分かること |
|---|---|---|
| ステップ応答 | 入力の変化が 1 回だけ入る範囲。先頭と末尾は変化前後の定常の区間にする | 応答開始遅れ、遅れ時間 Td、立ち上がり時間 Tr、時定数 τ、むだ時間 L、整定時間 Ts、オーバーシュート、定常ゲイン |
| ヒステリシス・入出力特性 | 入力が往復する範囲 | 感度、オフセット、直線性誤差、最大ヒステリシス、ループ面積 |
| 相互相関（遅れ） | 連続的に変化する区間 | 遅れ（サンプル間隔より細かく）、相関係数 |

- ステップ応答では、入力の変化の開始・応答開始・50%・整定の時刻に、グラフの上で印が付きます。
- ヒステリシスは、入力が増えているか減っているかの判定を平滑化します（既定でオン）。判定にだけ使い、指標には平滑化
  しない値を使います。オフにして判定が乱れると、差が小さく見積もられるので、結論の文で注意が出ます。
- ステップ応答で雑音が多いときは、「解析の前にローパスフィルタをかける」をオンにします。
- 応答の遅れがあるとループが開くので、測ったヒステリシスには遅れの分も含まれます。分けたいときは入力を
  ゆっくり変化させた区間を選んでください。
- 別のファイルのチャンネルを使うときは、開くときに「同じ時計」と答えるか、「時刻の対応付けと補間」を開いて
  時刻オフセットを指定します。指定しないと計算しません（異なる装置の時刻を勝手に揃えないため）。
  補間は 2 つのチャンネルが重なる範囲の中だけで行い、欠損区間はまたぎません。行った変換は結果に表示されます。
- 相互相関は等間隔の時刻が必要です。周波数の違うファイルでは「等間隔の時刻」に対応付けてください。


## 解析コアの使い方

時刻 [s] と値の NumPy 配列を渡します。処理の条件は pydantic モデルで指定します。
時刻が秒以外の単位なら、渡す前に秒へ換算してください。

```python
import numpy as np
import polars as pl

from experiment_workbench.analysis import (
    ButterworthFilter,
    Differentiator,
    Integrator,
    KalmanFilter,
    KinematicSystem,
)
from experiment_workbench.model import (
    ButterworthKind,
    ButterworthParams,
    DerivativeParams,
    IntegralParams,
    KalmanInitialState,
    KinematicSystemParams,
)

frame = pl.read_csv("data/synthetic/trial_001/high_rate.csv")
t = frame["time_s"].to_numpy().astype(np.float64)
accel = frame["accel"].to_numpy().astype(np.float64)

# 5 Hz のゼロ位相ローパスフィルタ → 積分
lowpass = ButterworthFilter(ButterworthParams(kind=ButterworthKind.LOWPASS, cutoff_hz=5.0))
smoothed = lowpass.apply(t, accel)
velocity = Integrator(IntegralParams(initial_value=0.0)).apply(t, smoothed)
jerk = Differentiator(DerivativeParams()).apply(t, smoothed)

# ミリ秒の時刻を秒に換算し、位置の観測からカルマンフィルタで位置・速度を推定
low = pl.read_csv("data/synthetic/trial_001/low_rate.csv")
t_low = low["time_ms"].to_numpy().astype(np.float64) / 1000.0
position = low["position"].to_numpy().astype(np.float64)
system = KinematicSystem(
    KinematicSystemParams(process_noise_density=10.0, measurement_noise_std=0.01)
)
initial = KalmanInitialState(state=[position[0], 0.0], covariance=[[1e-4, 0.0], [0.0, 10.0]])
result = KalmanFilter(system, initial).run(t_low, position)
estimated_position, estimated_velocity = result.states[:, 0], result.states[:, 1]
```

- 適応 KF にするには `KalmanFilter(..., adaptive=AdaptiveNoiseParams(method=...))` を渡します。
- EKF にするには `NonlinearSystem` に状態遷移・観測の関数とそのヤコビアンを渡します。
- 入力が前提を満たさない場合は `AnalysisInputError` になります。例えば NaN を含む信号にフィルタをかけた場合や、
  欠損区間のある信号に等間隔前提の処理をかけた場合です。値を勝手に補間・除去することはありません。
  カルマンフィルタだけは、NaN の観測を欠測として扱い、予測でつなぎます。

## 合成データの生成

```bash
uv run ewb-synthetic --output data/synthetic                 # 既定: 180 秒 × 3 試技
uv run ewb-synthetic --output data/synthetic-short --duration 10 --trials 3 --seed 1
```

出力先は空のディレクトリを指定してください（既存ファイルを上書きしないよう、空でなければ中止します）。
`data/` は `.gitignore` 済みです。

```text
data/synthetic/
├── manifest.json        # 生成条件と真値（運動のパラメータ、ノイズ、時刻オフセット、仕込んだ異常）
├── trial_001/
│   ├── high_rate.csv    # time_s, accel, true_accel, true_velocity, true_position（既定 1000 Hz）
│   ├── low_rate.csv     # time_ms, position, true_position, true_velocity（既定 100 Hz）
│   └── io_pair.csv      # time_s, input, output, true_input, true_output（高レートと同じ時計）
├── trial_002/ ...       # 一部区間の行が欠けている（時刻の飛び）
├── trial_003/ ...       # position の一部区間が NaN
└── broken/              # 空・ヘッダーのみ・列名重複・cp932・NaN/空欄・時刻逆転・時刻重複
```

- 観測列（`accel`・`position`）にはノイズなどが乗っています。解析の入力に使います。
- 真値列（`true_` で始まる列）は解析的に計算した正解です。フィルタ・積分・カルマンフィルタの結果の評価に使います。
- high_rate と low_rate は周波数・時刻原点・時刻の単位が異なります。時刻を揃える処理は明示的に行う前提です。
- io_pair は、むだ時間・時定数・遊びの幅が既知の系の入力と出力です（目録の `io_system`）。前半はステップ入力、
  後半は三角波の入力で、入出力関係の解析の確認に使います。

## プロジェクトフォルダの構成

```text
my-experiment/
├── project.json       # プロジェクト情報と保存形式バージョン
├── metadata.sqlite    # 実験 / 試技 / Source / Channel / Event
├── originals/         # 取り込んだ元データのコピー（Source ごとのフォルダ）
├── datasets/          # 正規化データ（Parquet。秒に換算した時刻 __time_s と各チャンネル）
├── derived/           # 解析の計算結果のキャッシュ（<解析 ID>/<条件の指紋>.parquet。消しても再計算できる）
├── pipelines/         # 保存した解析の条件（<解析 ID>.json）
├── views/             # 表示設定（JSON）
└── exports/           # CSV、画像等
```

メタデータ内のパスはすべてプロジェクトルートからの相対パスなので、フォルダを移動しても開き直せます。

## ソースコードの構成

```text
src/experiment_workbench/
├── model.py               # pydantic モデルのみ（データ受け渡し用の型・解析条件・解析結果・表示状態）

├── timebase.py            # 時刻の単位換算と、Source どうしの時刻を比較できるかの判定

│   ├── signal_processing.py  # 入力検証・フィルタ・微分・積分
│   ├── kalman.py             # 線形 KF・EKF・適応 KF
│   ├── alignment.py          # 2 チャンネルの時刻の対応付け（補間）
│   ├── input_output.py       # 相互相関・ステップ応答・ヒステリシス
│   ├── transforms.py         # 値の変換・時間の処理・区間統計
│   └── runner.py             # 保存できる解析の実行・結果の表示用データ・キャッシュとの変換・GUI の初期値

│   └── project_store.py   # プロジェクトフォルダ、元データ・正規化データ・表示設定・解析の読み書き
├── ui/
│   ├── main_window.py     # メイン画面と起動（ewb コマンド）
│   ├── plot_workspace.py  # 縦並べ表示
│   ├── import_dialog.py   # 読み込み設定の確認ダイアログ（判定できないときだけ出す）
```
